# FIGHTERS

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 1台のキーボードで2人が対戦する2D格闘ゲーム
* CPU対戦も可能
* 相手の体力を0にするか、制限時間終了時に体力が多いほうが勝ち
* 参考URL：[サイトタイトル](https://参考にしたページのURL)

## 操作方法
| 操作 | P1 | P2 |
| --- | --- | --- |
| 左右移動 | A / D | ← / → |
| ジャンプ | W | ↑ |
| パンチ | C | , |
| アッパー | F | K |
| キック | V | M |
| 必殺技 | G | J |
| 上防御 | R | O |
| 下防御 | T | P |

* タイトル画面：1/2/3で2P/CPU/Contorols、Esc で終了
* CPU難易度選択画面：1/2/3でweek/normal/strong、Escでタイトルに戻る
* 決着後：R でリスタート、Esc で終了

## ゲームの実装
### 共通基本機能
* 2人のキャラクターの描画（`fig/p1.png`, `fig/p2.png` がなければ色付きの四角で代用）
* 左右移動、ジャンプ（重力つき）、キャラ同士の押し合い、画面端の制限
* 常に相手の方を向く
* 攻撃と当たり判定（1回の攻撃で1ヒット、のけぞり・ノックバックあり）
* 体力ゲージ、制限時間（60秒）、勝敗判定、リスタート
* 背景画像の表示（`fig/bg.png` がなければ単色で代用）


### 分担追加機能
* CPU対戦とメニュー画面（担当：中村 匠）： CPU対戦の追加とタイトル・メニュー画面
* バリア（担当：西井 祥平）： 上段と下段の防御機能追加
* UI（担当：立原 翔真）： キャラの動きとモーション、細かなディティール
* SEとBGMの実装（担当：櫻井 俊吾）： 裏で流れる音楽とP1のモーションの音を実装
* 基本技の実装（担当：松本 龍哉）：　パンチ以外にキックやアッパーのモーション実装
* 必殺技の実装（担当：船津 佑斗）：　ゲージをためて必殺の一撃を打てるぞ！！！

### CPUの仕組み
* 難易度ごとに思考速度や行動判断が更新されている
* 難易度が高いほど思考速度や攻撃確率、回転角率が上がる

### メモ
* 実行時のカレントディレクトリずれを防ぐため、ファイル冒頭で `os.chdir(os.path.dirname(os.path.abspath(__file__)))` を実行している
* 画像は `fig/`、音声は `sound/` に置く
* キャラのドット絵はAI生成画像を使用（生成に使ったツール名を書く）
* 変数名・関数名は `snake_case`、クラス名は `PascalCase`、定数は `UPPER_CASE` で書く
* 関数・メソッドには型ヒントとdocstringを書く
* 数値の調整値（速度・ダメージなど）はファイル冒頭の定数にまとめてある
* キャラの処理は `Fighter` クラスにまとめてある。キャラの位置は `rect`、向きは `facing`（右:+1, 左:-1）で管理する
* キー割り当ては `KeyConfig` で管理する。キーを追加するときは `KeyConfig` と `P1_KEYS` / `P2_KEYS` に追記する
* `main()` のループは「入力 → 更新 → 当たり判定 → 描画」の順
